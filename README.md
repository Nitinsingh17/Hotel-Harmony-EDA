## Project Overview

Exploratory Data Analysis of hotel bookings using Python to study booking patterns, cancellations, guest preferences, average daily rates (ADR), and seasonal trends. The project focuses on cleaning booking data and using visualizations to understand hotel operations.

## Dataset

- **Source:** [Hotel Booking Demand - Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)
- **Dataset Link:** [https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)
- **Kaggle File Path:** `/kaggle/input/datasets/jessemostipak/hotel-booking-demand/hotel_bookings.csv`
- **Size:** 119,390 records and 32 columns in the original dataset
- **Key Features:** Hotel, Lead Time, Cancellations, Arrival Month, Market Segment, ADR, Special Requests, and Guest Details

## Requirements & Technologies

- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook / Kaggle
- **Techniques:** Data Cleaning, Data Manipulation, Exploratory Data Analysis, Correlation Analysis, Data Visualization

## Project Workflow

1. Loaded and examined hotel booking records, missing values, and data types.
2. Handled missing data, converted dates, and removed duplicate rows.
3. Analyzed booking trends, hotel types, cancellations, ADR, and guest behavior.
4. Used charts and statistical summaries to explore relationships and seasonal patterns.

## Challenges Faced

- Handling missing values in country, agent, company, and children fields.
- Identifying duplicate records and preparing dates for analysis.
- Interpreting cancellation patterns and ADR-based comparisons accurately.

## Insights & Recommendations

The analysis compares City and Resort hotels, explores booking lead times and cancellation rates, and examines seasonal bookings, market segments, special requests, and room preferences.

**Recommendations for Further Analysis:**

- Explore factors associated with booking cancellations to support retention strategies.
- Compare seasonal demand and ADR trends to improve pricing decisions.
- Investigate guest preferences and booking channels to support hotel operations.
